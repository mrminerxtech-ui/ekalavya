Quick Setup
One command per farm
Run on any PC inside the farm. It dials outward — no port forwarding, works through NAT.
# Install
git clone https://github.com/yourrepo/mmx-agent && cd mmx-agent && npm install
# Configure .env
MMX_SERVER=wss://your-server.com/agent   AGENT_KEY=your-secret
FARM_NAME="Farm Dubai"   LOCAL_SUBNET=192.168.1.0/24
# Start (auto-reconnects forever)
npm start

🔗 Merge Duplicate Machine
Same physical miner, two records — usually because it changed IP (a reboot, a power outage) before it had a MAC or serial number on file to be recognised by. Pick which record to keep. Its name, customer assignment and history stay; the other record's live readings (IP, hashrate, status, etc.) are copied onto it, and the other record is deleted.
